A deterministic Node 22 TypeScript program that writes a single deadpan one-star review of sleep — an everyday essential everyone relies on — to `/output/entry.txt`. The review files a flat, earnest complaint about paying eight hours a night and waking up tired anyway, then lands its twist in the last few words by calling it the worst return policy ever seen. The program validates the review itself before writing: it refuses with a hard error if the text is outside 1–160 characters, spans more than one line, or uses an exclamation mark, so an invalid entry can never be produced.

## Run it

```sh
node main.ts
```
